## 0. 원칙

1. **다크가 기본.** 방송 중 OBS 옆에 띄워두는 도구라서 어두운 화면이 기본이다. 라이트 모드는 설정(p14)에서 고를 수 있고, 같은 토큰 이름에 라이트 값을 넣는다.
2. **색은 신호로만.** 화면 대부분은 무채색이다. 색은 아래 네 가지 역할에만 쓴다.
   - `brand` (블루): 주 버튼, 공지 태그, 토글 ON, 선택 상태
   - `live` (BI 블루): 지금 재생 중인 것, 선택된 탭 밑줄, Dock에서 켜진 위젯 점 **[v1.2]**
   - `warning` (주황): 일시정지 중, 큰 금액 강조
   - `danger` (빨강): 숫자 배지, 차단, 삭제 같은 되돌릴 수 없는 동작
3. **유리 효과·큰 모서리·그림자 없음.** 위젯은 1px 선으로 구분한다. 그림자는 Dock과 떠 있는 레이어(모달·팝오버·토스트)에만 쓴다.
4. **촘촘하게.** 한 화면에 후원을 최대한 많이 보여주는 게 우선이다.

> **BI 컬러 [v1.2]** — 투네이션 공식 로고(2026 브랜드 리소스) 기준
>
> | 이름 | 값 | 로고에서 |
> |---|---|---|
> | BI 블루 | `#519CFF` | ＋ 기호와 오른쪽 원 |
> | BI 라이트 블루 | `#A8CDFF` | 왼쪽 원 (BI 블루 50%를 흰 바탕에 얹은 색) |
> | BI 잉크 | `#141619` | 워드마크 글자 |
>
> BI 블루 위 흰 글자는 2.78:1로 버튼 글자 기준(4.5:1)에 못 미친다. 그래서 **BI 블루는 표시용**(다크의 `live`, 로고, 강조 점·막대)으로 쓰고, **흰 글자가 올라가는 채움(주 버튼·토글·공지 태그)은 같은 색상(hue)을 진하게 한 `brand` #006AF5**(흰 글자 4.79:1)를 쓴다. 다른 곳에 hex를 직접 쓰지 말고 반드시 토큰을 참조할 것.

## 5. 컴포넌트 규칙 요약

- **위젯 틀**: `surface` 바탕, 1px `line` 테두리, `radius-widget`. 제목줄 44px, 아래 1px `line`. 제목 왼쪽, 위젯 조작 버튼(분리·압정·닫기)은 오른쪽에 `text-tertiary` 아이콘으로.
- **탭**: 밑줄형. 선택 = `text` + 2px `live` 밑줄, 비선택 = `text-secondary`. 세그먼트 컨트롤(알약형)은 쓰지 않는다. 설정의 테마·글자 크기처럼 2~3개 중 하나 고르는 곳만 사각 세그먼트(`surface-raised` 바탕, 선택 칸 `brand`)를 쓴다.
- **버튼**
  - 주 버튼: `brand` 바탕, `text-on-brand`, `radius-control`. 비활성 = `surface-sunken` 바탕 + 1px `line` + `text-tertiary` **[v1.1]**
  - 보조 버튼: `surface-raised` 바탕 + 1px `line-strong`
  - 외곽선 버튼: 투명 + 1px `line-control`
  - 위험 버튼: `danger` 바탕, 흰 글자
  - 확인 창 버튼은 오른쪽 아래 가로 배치 [취소](보조) · [확인](주). **삭제·차단·초기화·종료처럼 되돌릴 수 없는 확인은 [확인] 자리에 위험 버튼**을 쓰고 라벨을 동작 이름으로 쓴다(예: [삭제]) **[v1.1]**
  - 행 위 조작 버튼(차단 등): 평소 외곽선 + 색 아이콘, 버튼에 올렸을 때만 색 바탕 **[v1.1]**
- **토글**: ON = `brand`, OFF = `line-strong`. iOS 초록 토글은 없앤다.
- **슬라이더** **[v1.1]**: 트랙 4px `line-strong`(다크는 `line-control`), 채운 부분 `brand`, 손잡이 16px 원 `#FFFFFF` + 1px `line-strong` + `shadow-float`의 1/3 세기. 브라우저 기본 모양을 쓰지 않는다.
- **창 버튼** **[v1.1]**: 최소화·최대화·닫기는 테두리 없음, hover 때만 `surface-raised` 바탕(닫기는 `danger` 바탕 + 흰 아이콘).
- **표(후원 리스트)**: 헤더 행 `surface-sunken`. 행 사이 1px `line-subtle`, hover 시 `surface-sunken`.
- **재생 중인 후원 행(p43)**: `brand-tint` 바탕 + 왼쪽 3px `live` 막대(`box-shadow: inset 3px 0 0`). 빨간 막대 깜빡임은 없앤다.
- **퀵 제어**: 일시 정지 버튼과 스킵 버튼(아이콘만, 툴팁·접근성 이름 "○○ 스킵")을 1px 테두리로 묶은 한 덩어리. 평소 `surface-raised`, 일시 정지 중에는 그 묶음 전체가 `warning` 바탕 + `text-on-warning` 글자 + 라벨 "○○ 일시 정지 중" **[v1.1: 띄어쓰기는 기획서 문구를 따른다]**. 버튼 높이는 위젯 높이에 맞춰 44~96px.
- **숫자 배지**: `danger` 바탕, 흰 `badge` 글자, `radius-pill`, 최소 16px.
- **Dock**: `surface` + 1px `line` + `shadow-float`. 켜진 위젯과 압정 켜짐 = `surface-raised` 바탕 + `text` 아이콘 + 아래 4px `live` 점 **[v1.1]**. 꺼진 위젯 = 투명 + `text-tertiary` 아이콘.
- **공지 바**: `brand-tint` 바탕 + 1px `brand-tint-line`, 왼쪽에 `brand` 바탕 "공지" 태그. 서버의 관리자 지정 색(`background`/`color`)은 쓰지 않는다 **[v1.1]**.
- **알림 목록**: 안 읽은 알림 = `brand-tint` 바탕 + 굵은 제목, 읽은 알림 = `surface` 바탕 + `text-secondary`.
- **토스트**: 화면 아래 가운데, Dock 바로 위. 상단 바 아이콘을 가리지 않는다.
- **포커스**: 키보드 포커스 시 2px `live` 바깥선(`outline-offset: 2px`).

- ⚠ `-dark` 파일은 공식 다크 버전을 받기 전까지 쓰는 **임시 보정본**이다. 브랜드 리소스 zip에 반전(화이트) 로고나 SVG가 있으면 그것으로 바꾼다.
- **CSS로 로고를 그리지 않는다.** 지금 코드의 `Logo` 컴포넌트(＋ 글자와 원 두 개를 CSS로 그린 것)는 이미지로 교체한다. 테마에 따라 라이트/다크 파일을 바꿔 쓴다.
- 크기: 상단 바 영문 로고 높이 **20px**, 스플래시·로그인 국문 또는 영문 로고 높이 **32px**. 작은 자리(위젯 독립창 제목, 파비콘, 트레이)는 심볼만.
- 여백: 로고 주변에 심볼 ＋ 기호 폭만큼 비운다. 로고 색·비율을 바꾸거나 그림자·외곽선을 넣지 않는다.

## 할 일

1. **룰렛 색 변경 (L8)**: `src/lib/kindColors.ts`에서 룰렛을 다크 `#FF5FA2`, 라이트 `#C11574`로 바꾼다. 유튜브 빨강과 색 계열(빨강 vs 분홍)로 구분한다. 종류 이름이 항상 같이 보이므로 색만으로 구분하지 않아도 된다.
2. **위험 동작 확인 창**: 삭제·차단·초기화·로그아웃·프로그램 종료처럼 되돌릴 수 없는 동작의 확인 창은 [확인] 자리를 `danger` 버튼으로 바꾸고, 라벨을 동작 이름으로 쓴다(예: [삭제], [차단], [초기화]). 라벨 문구는 기획서에 있는 문구가 있으면 그것을 쓰고, 없으면 동작 이름 그대로 쓴다. 바꾼 확인 창 목록을 결과 문서에 적는다.
3. **슬라이더**: 볼륨 제어 등 `input[type=range]`를 토큰 §5 슬라이더 규칙대로 직접 그린다(다크에서 브라우저 기본 밝은 트랙이 보이지 않게). 키보드 조작(←→, Home/End)과 포커스 링은 유지한다.
4. **공지 바**: 관리자 지정 색을 쓰지 않는 현재 처리를 유지한다. 서버 데이터의 `background`/`color` 필드는 무시하되, 나중에 다시 쓸 수 있도록 데이터 타입에서는 지우지 않는다.
5. **`toona-design-tokens.md` v1.1과 코드 대조**: 문서 값과 `src/index.css`·`kindColors.ts` 값이 모두 같은지 확인하고, 다르면 문서가 아니라 **결과 문서에 적어서** 알려 준다.

## 바꾼 내용

### 1. 토큰

- `tailwind.config.js`: 기본 팔레트(slate·blue·red …)를 **통째로 없애고** 토큰 이름만 남겼다. 토큰이 아닌 색 클래스를 쓰면 스타일이 아예 생기지 않으므로 빠뜨린 곳이 바로 드러난다.
  - 색 클래스 이름: `bg-canvas`, `bg-surface` / `-raised` / `-sunken`, `border-line` / `-subtle` / `-strong` / `-control`, `text-text` / `-body` / `-secondary` / `-tertiary` / `-on-brand` / `-on-warning`, `text-link`, `bg-brand` / `-hover` / `-tint` / `-tint-line`, `live`, `warning`, `danger`
  - 모서리 `rounded-widget|card|control|dock-item|tag|pill`, 그림자 `shadow-float`, 글꼴 `font-sans|num`
  - 글자 `text-title-widget|body|caption|micro|badge` (rem)
  - 겹침 순서 `z-dock < titlebar < popover < sheet < modal < alert < entry < toast`
- `src/index.css`: `:root` = 라이트, `.dark` = 다크 값. 테마 전환은 변수만 바뀐다. `.glass`, `.glass-strong`, `.segmented`를 삭제했다.
- 재생 중인 행 `.playing-row`: 깜빡임을 없애고 `brand-tint` 바탕 + 왼쪽 3px `live` 막대로 바꿨다.
- 기본 테마: 다크. 첫 실행 화면이 번쩍이지 않도록 `index.html`의 `<html>`에도 `dark`를 미리 넣었다. 이미 라이트를 저장한 사용자는 라이트로 열린다.
- 후원 종류 색: `src/lib/kindColors.ts` 한 파일에 모았다. 앱 시작 때 `--kind-*` 변수로 등록하고, 화면은 `kindColor(kind)`로 참조한다.
- 키보드 포커스: 2px `live` 바깥선을 전역으로 적용했다.
- `docs/design/ios26-tokens.md`를 삭제했다.

### 2. 글꼴

- `pretendard`(가변, 다이나믹 서브셋)와 `@fontsource/ibm-plex-mono`(latin 500·600)를 npm으로 넣어 번들에 포함했다. CDN을 쓰지 않는다.
  - 설치형에서 `document.fonts.check`로 두 글꼴 모두 로드되는 것을 확인했다.
- 금액은 모두 `Cash` 컴포넌트를 쓴다(`font-num` 600). 50,000 캐시 이상은 `warning` 색이다. 후원 리스트·뽑기·대기 중인 후원·투네애드·크루·벽지에 적용했다.
- 텍스트 크기(100/125/150%)는 `html { font-size }` 하나로 적용한다. 이전의 위젯 본문 `zoom` 방식은 없앴다.

### 4. 화면별

- **상단 바**: 높이 44. 공지는 `brand-tint` 바 + "공지" 태그. 알림·설정·창 버튼은 36×36 사각 + 1px `line`.
- **위젯 틀**: 토큰 §5대로 바꿨다. 제목줄에 위젯이 자기 조작을 올릴 수 있는 자리(`WidgetHeader`)를 만들었다. 모바일처럼 틀이 없는 곳에서는 같은 모양의 줄로 그린다.
- **후원 리스트**
  - 탭은 밑줄형이고 제목과 같은 줄에 있다. 필터·정렬은 같은 줄 오른쪽에 있다.
  - 종류 칸은 8×8 점 + 이름이고 **최소 120px**이다. 이 최소 폭은 텍스트 크기에 비례해 넓어지고, 사용자가 줄여도 그 아래로 내려가지 않는다.
  - 닉네임과 아이디는 한 줄에 놓았다. 폭이 모자라면 아이디부터 말줄임된다.
  - 행 높이 46. hover 시 `surface-sunken`이 된다(이전의 떠오르는 그림자 효과는 없앴다).
- **퀵 제어**: 일시정지와 스킵을 한 묶음으로 만들었다. 일시정지 중에는 묶음 전체가 `warning`이 되고 라벨은 "○○ 일시 정지 중"이다.
- **대기 중인 후원**: 카드는 `surface-raised` + 1px `line` + `radius-card`. 종류 태그는 외곽선형이다. 버튼은 주 버튼과 외곽선 버튼 한 쌍이고, 퀘스트 [실패]도 외곽선으로 바꿨다. 개수 배지는 위젯 제목 옆으로 옮겼다.
- **Dock**: 켜진 위젯은 `surface-raised` + 아래 4px `live` 점, 꺼진 위젯은 `text-tertiary`, 압정이 켜지면 처음에는 `brand-tint` + `link`였으나, 후속 반영에서 위젯과 같은 규칙으로 통일했다(아래 5번). 아이콘 버튼은 44px로 고정했다(텍스트 크기에 따라 커지지 않음).
- **나머지**(다른 위젯·설정·프리셋·진입 화면·모바일): 토큰으로 옮기고 어색한 곳만 정리했다. 설정의 테마·텍스트 크기는 사각 세그먼트로, 설정 왼쪽 탭 선택은 `brand-tint` + `live` 막대로 바꿨다.

## 토큰으로 처리하지 못한 곳

- **목업 썸네일**(`src/api/mockData.ts`): 가짜 영상·광고 썸네일 SVG의 그라데이션 색이다. UI 색이 아니라 체험용 이미지라 그대로 뒀다. 실서버 연동 시 실제 썸네일로 바뀐다.
- **광고 팝업 배너 위 조작**(이전/다음 버튼, 점): 이미지 위에 얹는 검정/흰색 반투명이라 테마와 무관하게 `black/40`, `white`를 그대로 썼다.
- **`index.css` 토큰 정의**: 토큰 값 자체라 hex를 주석으로, 그림자 rgba를 값으로 두었다.
- **브라우저 기본 컨트롤**: 체크박스·슬라이더는 `accent-brand`만 적용했다. 다크에서 슬라이더 트랙은 브라우저 기본(밝은 회색)이다. 맞추려면 별도 슬라이더 디자인이 필요하다.
- **SNS 로그인 버튼**: 유튜브·치지직·트위치·카카오의 고유색과 로고는 토큰에 없어 보조 버튼(글자만)으로 바꿨다.
- **공지 바 색**: 서버 공지 데이터의 `background` / `color`(관리자 지정 색)를 더 이상 쓰지 않고 토큰(`brand-tint`)으로 고정했다. 관리자 지정 색을 살려야 하면 알려 달라.

## 디자인 판단이 필요했던 곳

1. **"일시정지 중" 띄어쓰기**: HANDOFF는 "○○ 일시정지 중"이지만 기획서·기존 버튼 문구가 "알림 일시 정지"라서 "알림 일시 정지 중"으로 맞췄다(문구는 바꾸지 않는다는 원칙).
2. **스킵 버튼**: 시안처럼 아이콘만 두고, 툴팁과 스크린리더용 이름으로 "알림 스킵" 등을 남겼다. 이전에는 글자가 보였다.
3. **위젯 아이콘**: 시안에 없어 위젯 제목줄의 아이콘과 드래그 손잡이(⋮⋮)를 뺐다. 제목줄 전체를 끌면 이동되는 것은 그대로다.
4. **표 → 카드 전환 폭**: 후속 반영에서 다시 바꿨다(아래 3번 참고).
5. **"크리에이터TTS 구독"**: 후속 반영에서 넓은 화면은 156px로 넓혀 다 보이게 했다. 중간 폭에서는 120px로 말줄임되고, 마우스를 올리면 전체 이름이 나온다.
6. **작은 위젯 제목줄 40px**: 토큰에 "작은 위젯 40px"이 있지만 어떤 위젯이 작은지 정의가 없어 모두 44px로 두었다.
7. **글자 크기 밖의 여백**: 여백·높이도 Tailwind 기본(rem)이라 텍스트 크기를 키우면 같이 커진다. 상단 바·Dock·위젯 제목줄·버튼·토글 높이는 토큰 px로 고정했다.
8. **확인 창 버튼**: iOS식 세로 쌓기 대신 [취소](보조) · [확인](주) 가로 배치로 바꿨다. 위험 동작 확인(삭제·종료)을 `danger`로 둘지는 다음 HANDOFF에서 정해 주면 맞추겠다.
9. **로그인 화면**: 바탕 `canvas` 위에 `surface` 카드로 감쌌다. 진입 화면 세부 디자인은 다음 HANDOFF 기준으로 다시 맞춘다.

### 남은 판단 사항

- **L8 룰렛·유튜브 점 색**: 두 빨강의 대비가 1.36:1로 거의 같아 구분이 어렵다(다크도 비슷). 색 계열을 고르는 일이라 바꾸지 않았다.

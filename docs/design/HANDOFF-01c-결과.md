### 퀵 제어: 칸 크기에 맞춘 배치

좁고 낮은 칸(예: 오른쪽 열 아래, 약 330×130px)에서 세 묶음이 세로로 겹치던 문제를 고쳤다. 위젯이 자기 칸의 너비·높이를 재서 배치를 고른다.

| 배치 | 조건 | 모양 |
|---|---|---|
| 가로 | 묶음 하나가 180px(× 텍스트 배율) 이상 | 세 묶음 가로 한 줄, 전체 라벨 "알림 일시 정지" |
| 세로 | 가로가 안 되고 세 줄이 각 44px 이상 들어갈 때 | 세 묶음 세로, 전체 라벨 |
| 나눔 (새로 추가) | 좁고 낮을 때 (칸 56px × 배율, 높이 48px 이상) | 가로 세 칸, 각 칸은 위 일시 정지(아이콘 + "알림") / 아래 스킵 |
| 아이콘 | 그마저 안 될 때 | 아이콘만. 이름은 툴팁·스크린리더로 |

- 확인한 크기:
  - 오른쪽 열 아래 334×127(100%·150%·일시 정지 중), 233×127, 334×364, 1260×127(100%·150%)
  - 모든 경우 묶음끼리 겹치거나 위젯 밖으로 나가지 않는다.
- 나눔 배치에서 일시 정지 중이면 칸 전체가 `warning`이고, 라벨은 "알림"으로 줄인다. 전체 문구 "알림 일시 정지 중"은 툴팁과 스크린리더 이름으로 남겼다.

### Dock: 켜짐/꺼짐을 색으로 대비

| 상태 | 이전 (토큰 v1.1 §5) | 지금 |
|---|---|---|
| 켜짐 (위젯·압정) | `surface-raised` 바탕 + `text` 아이콘 + `live` 점 | **`brand-tint` 바탕 + 1px `brand-tint-line` + `link` 아이콘** + `live` 점 |
| 꺼짐 | 투명 + `text-tertiary` | 그대로 |
| 퀵 제어 일시 정지 중 | `warning` 바탕 | 그대로 |

회색 바탕만으로는 켜짐과 마우스 올림(hover)이 비슷해 구분이 약했다. 켜짐을 BI 블루 계열로 바꾸고 hover는 회색으로 남겨 세 상태(꺼짐·hover·켜짐)가 다르게 보이게 했다.

## 확인이 필요한 곳

1. **다크 로고**: 지시서대로 임시 보정본(`-dark`)을 썼다. 공식 반전 로고나 SVG가 오면 `src/assets/brand/`의 `-dark-64` / `-dark-96` 두 파일만 바꾸면 된다.
2. **스플래시는 영문, 로그인은 국문**: §6이 "국문 또는 영문"이라 아래 문구 언어에 맞춰 골랐다. 하나로 통일하려면 알려 달라.
3. **독립창 제목 앞 심볼**: HANDOFF-01에서 위젯 제목 아이콘을 뺐는데, §6의 "작은 자리(위젯 독립창 제목)"에 따라 독립창에만 심볼을 붙였다. 캔버스 안 위젯에는 붙이지 않았다.
